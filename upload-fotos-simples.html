📸 Upload de Fotos - Guia Rápido

⚠️ Problema Identificado

A ferramenta de upload precisa rodar em um servidor web. Não funciona abrindo o arquivo HTML diretamente.

✅ Solução: Usar Servidor Local

  1. Abrir o Terminal (PowerShell ou CMD)
  2. Navegar até a pasta do projeto:
cd c:\Users\tobias.matos\.gemini\antigravity\playground\spatial-interstellar
  1. Iniciar o servidor:
npm run dev
  1. Abrir no navegador:
http://localhost:5173/upload-fotos.html

🚀 Alternativa Mais Simples: Upload Direto no Supabase

Opção 1: Upload Manual no Supabase Dashboard

  1. Ir para Supabase Dashboard
  2. Abrir Storage → member-photos
  3. Clicar em "Upload file"
  4. Selecionar as fotos
  5. Copiar a URL de cada foto
  6. Executar no SQL Editor:
UPDATE members
SET photo_url = 'URL_DA_FOTO_AQUI'
WHERE name = 'NOME_DO_MEMBRO';

Opção 2: Aguardar Integração da UI

Posso integrar o botão de upload diretamente no app principal. Aí você poderá fazer upload direto pelo celular/computador sem precisar de ferramentas extras.

Tempo estimado: 10-15 minutos

💡 Qual Opção Você Prefere?

  1. Servidor Local: Usar npm run dev e abrir upload-fotos.html
  2. Upload Manual: Fazer upload no Supabase Dashboard e atualizar via SQL
  3. Aguardar UI: Eu integro o upload no app principal (recomendado!)
